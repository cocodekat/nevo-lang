§01Overview

A FastAPI-based file hosting server with a web interface for browsing and accessing files remotely. Files placed in the server's /files directory are automatically made available through the site, where users can browse them and open or stream supported media such as video. The FastAPI backend serves the files over HTTP, while the interface determines how they're presented. Built as a simple foundation for personal cloud storage, private file sharing, or a self-hosted platform not unlike a basic Netflix.
