§01Overview

A FastAPI-based messaging backend that lets authenticated users send and receive messages through a REST API. Users authenticate with HTTP Basic Auth, and messages are stored persistently with sender, recipient, content, and timestamp. Separate endpoints handle authentication, sending, and retrieving a user's inbox. Built as a backend/API project without a graphical interface.
