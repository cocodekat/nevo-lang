# overview

A FastAPI-based messaging backend that allows authenticated users to send and receive messages through a REST API. Users authenticate using HTTP Basic Authentication, while messages are stored persistently with sender, recipient, content, and timestamps. The server exposes separate endpoints for authentication, sending messages, and retrieving a user's inbox. The project was built as a backend/API project without a graphical interface.
