# overview

Nevo is a programming language built entirely in C, targeting aarch64-apple-darwin. I originally created it as a way to learn more about ARM64 assembly and how programming languages work under the hood. It currently supports core features such as functions, variables, loops, mathematical operations, and printing. Its syntax isn’t based on any particular language — I experimented with different ideas and gradually shaped it into what it is today.
